# Лабораторная работа: метод градиентного спуска

Программа реализует классический градиентный спуск для трех тестовых функций:

- Растригина
- Экли
- Розенброка

Для каждой функции реализован аналитический градиент.

Интерфейс позволяет менять:

- начальную точку X, Y;
- скорость обучения α;
- точность ε;
- максимальное число итераций;
- критерий остановки;
- тестовую функцию.

Программа строит:

1. карту линий уровня с траекторией движения;
2. 3D-поверхность функции и путь алгоритма;
3. график значения целевой функции по итерациям;
4. график нормы градиента по итерациям.

Дополнительно есть режим сравнения с алгоритмом имитации отжига.
Оба алгоритма запускаются на одной и той же выбранной функции и из одной начальной точки.

## Запуск

### macOS / Linux

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```

### Windows

```bash
py -m pip install -r requirements.txt
py main.py
```
